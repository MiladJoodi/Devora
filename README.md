# Devora

Devora is a full-stack developer publishing platform built with Next.js and TypeScript.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Zustand
- TanStack Query
- PostgreSQL
- Neon
- Drizzle ORM
- Zod
- Redis
- Vitest
- Husky
- Docker
- GitHub Actions

## Features

- Authentication & authorization
- Create, edit, and publish articles
- Categories and tags
- Comments and replies
- Likes and bookmarks
- Search, filtering, and pagination
- Image uploads
- Notifications
- Redis caching and rate limiting
- Background jobs
- Analytics
- Automated testing
- Dockerized deployment

## Goal

Devora is built as a production-oriented full-stack project to explore modern frontend and backend development with Next.js.
