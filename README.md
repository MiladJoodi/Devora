# Devora

> 🚧 **Work in Progress**
>
> Devora is currently under active development. Features, architecture, and APIs may change as the project evolves.

A full-stack developer publishing platform built with **Next.js, TypeScript, PostgreSQL, Drizzle ORM, and Redis**.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Zustand
* TanStack Query
* PostgreSQL
* Neon
* Drizzle ORM
* Zod
* Redis
* Vitest
* Husky
* Docker
* GitHub Actions

## Features

* Authentication & authorization
* Create, edit, and publish articles
* Categories and tags
* Comments and replies
* Likes and bookmarks
* Search, filtering, and pagination
* Image uploads
* Notifications
* Redis caching and rate limiting
* Background jobs
* Analytics
* Automated testing
* Dockerized deployment

## Project Status

Devora is an **actively developed project** focused on building a production-oriented full-stack application.

The feature set and architecture are still evolving, and some features may be incomplete or subject to change.

## Goal

Devora is built to explore modern **frontend and backend development with Next.js**, while applying production-oriented patterns such as caching, background jobs, testing, rate limiting, authentication, and containerized deployment.

## Development

This project is currently being developed and is not considered production-ready yet.
